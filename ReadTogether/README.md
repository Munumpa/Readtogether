# ReadTogether (project-specific README)

โฟลเดอร์นี้เป็นโค้ดของเว็บ ReadTogether (PHP + MySQL). เพื่อรันโปรเจ็กต์ให้ทำตามขั้นตอนใน repo root README.md

ตำแหน่งโค้ด: `ReadTogether/` (ไฟล์หลักเช่น index.php, books.php, admin_dashboard.php)

Notes:
- อย่าวางไฟล์ `.env` ที่มีรหัสจริงเข้าไปใน repo
- โฟลเดอร์ `uploads/` เก็บไฟล์ที่ผู้ใช้อัปโหลด — ควรลบหรือสำรองไฟล์จริงก่อนเผยแพร่
